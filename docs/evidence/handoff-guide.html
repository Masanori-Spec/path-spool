This kit contains adjacent-stage aggregates. It cannot prove that a band crossing multiple stages represents one original path. Use paths.json and contributions.json to recover the recorded row relationships. The app makes no causal, statistical or chart-accessibility guarantee.

1. Choose the correct CSV

Machine CSV preserves exact text. Quoting alone does not prevent spreadsheet formula execution. Import machine CSV as text using a tool you trust. Spreadsheet-safe CSV prefixes an apostrophe to formula-like text, changing those values; it is for inspection, not chart import or exact round-trip. Handling still depends on the spreadsheet. JSON retains exact labels and values.

2. Flourish alluvial handoff

Import flourish-machine.csv into the Sankey template. Bind Source, Target, Value, Step from, and Step to explicitly. Set alluvial mode. Step values are 1-based ordered integers. Source and Target contain generated alphanumeric node IDs, so distinct labels cannot collide under consumer label normalization. The Source label / Target label columns preserve source text; separate display-label columns carry optional overrides. These columns and nodes-machine.csv are an exact-text lookup; they are not the identity bindings. The initial chart therefore displays IDs. Review any display-label customization separately. Always bind Value, including when weights are zero. No chart account or consumer import has been exercised by this app.

3. Plotly figure JSON

Load plotly-figure.json as a figure with data and layout. Source and target arrays are zero-based indices into node.label. Display labels include IDs and escape markup; node.customdata preserves raw labels and the missing flag. Meta records the policy and stage names. This is a documented-schema handoff, not a rendered Plotly compatibility certification. Zero-weight records remain in the evidence but may have no visible band.

4. Evidence and exclusions

Row numbers count data records after the header (not physical file lines). Repeated item IDs stay as separate rows. paths.json preserves each retained row’s complete node sequence; contributions-machine.csv / contributions.json maps each adjacent link back to rows and weights; exclusions.json lists incomplete records removed under the exclude policy. Empty strings alone mean missing. Spaces and literal text such as “(missing)” remain real labels. Project JSON preserves the complete input table, mapping and selected policy for reimport.
